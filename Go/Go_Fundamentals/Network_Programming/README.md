并发是Go语言的特色，有效的管理并发对构建稳定健壮的程序至关重要，在Golang中，提供了context标准库，用于管理goroutine的生命周期，
传递上下文，控制超时取消等操作
示例：
    假设我们需要从多个api接口中并发的获取数据，如果某个接口超时，就将其请求取消


注意一些问题：
1.不传递山下文：如果一个函数创建了上下文，但并没有传递给其他函数或协程，这些函数和协程无法响应上下文相关的处理操作
2.忘记调用取消函数：使用有取消函数的上下文时，记得取消
3.协程泄露：有上下文的协程需要检查Done channel，当接收到信号时及时清理资源和退出
4.过度使用context.Background：没有取消和超时功能，很可能引发问题
5.传递nil的上下文：不要传递nil的上下文，会导致Panic
6.阻塞调用：应该将阻塞操作（比如IO）包装成使用上下文检查的调用，可以避免被挂起
7.过度使用上下文：上下文也并不是所有场景都使用，比如处理全局资源或者共享状态等，可能更使用锁或者channel
8.上下文存储在结构体中：应该将context显示的传递给需要的函数，否则可能会引起数据竞争，生命周期管理等问题
